# slide-creator

決まった型で図と文字を置いていく、スライド・ポスター作成ツール。PowerPoint の自由度をわざと下げ、
**「領域を上下か左右に分ける → 比率を決める → 各領域に何を入れるか、どう揃えるか」** を入れ子で書いた
設定ファイル（`layout.yaml`）を正本にする。人もAIも同じファイルを編集し、同じ CLI で確かめる。

- 出力：編集できる PPTX（画像は元画像のまま埋め込み、トリミングは PowerPoint の「トリミング」として残る）、PDF、PNG
- 状態：試作 v0.2（AI 用の CLI と、ブラウザ版の表示・編集画面）

## 準備

```bash
npm install
npm run demo          # 見本の画像を作り、検査し、examples/demo/out/ に PPTX と PDF を出す
```

PDF と PNG は Chrome で描く。見つからないときは環境変数 `SLIDE_CHROME` に実行ファイルの場所を入れる。

## プロジェクトの形

```
my-poster/
  layout.yaml     ← どこに何を置くか（正本）
  a.png, b.jpg …  ← 画像（layout.yaml と同じフォルダに置く。png / jpg / gif / svg。TIFF はブラウザで描けないので PNG にする）
  templates/      ← 使い回す型（任意。ファイル名が型の名前）
  out/            ← 書き出し先（自動）
```

## ブラウザ版

```bash
npm run serve        # http://127.0.0.1:8769/web/ を Chrome / Edge で開く
```

GitHub Pages に置けば、そのままブラウザで使える（ビルド不要の静的ファイル）。

- 「フォルダを開く」でプロジェクトフォルダを選ぶ。`layout.yaml` を直接読み書きする（Chrome / Edge のフォルダアクセス機能。Safari・Firefox は不可）。`layout.yaml` が無いフォルダなら雛形を作る
- 開発用：URL に `?demo` を付けると `examples/demo` を開く（保存はダウンロードになる。画面にボタンは無い）
- 左の欄の上の「スライド全体」で、1 枚の大きさ（幅・高さ・単位、縦横比とその固定、用紙）、全体の文字の大きさ（既定。pt）、全体の背景を決める（フォントは、ボックスを選んで出るサポートパネルで決める）。ボックスを選んでいるあいだは折りたたむ。PowerPoint の上限（1 辺 142.24 cm）を超えると注意を出す
- プレビューの上の帯：ページの選択（「1ページ」…）、「分割 ▾」（押すと下にマス目が出る。マウスを乗せた範囲の「行 × 列」に分ける。PowerPoint の表の挿入と同じ。1 行か 1 列なら、その向きだけに分ける）、「統合」（ドラッグで選んだボックスを 1 つにまとめる）、「複製して追加」（選んだボックスと同じ大きさ・同じ中身を、すぐ下に新しい行として足す。行の一部（左右に並ぶうちのいくつか）を選んだときは、同じ横の位置に置き、新しい行のほかの場所は空きにする。下のボックスは下にずれ、その分は下のほうの空きのボックスを縮めて埋める。空きが足りずスライドからはみ出すときは押せない）、ゴミ箱（選択中のボックスを削除）、虫眼鏡とつまみ（つまみは左上から右下へ 100〜800% で拡大。虫眼鏡を押すと、選んだボックスを左上に寄せ、いまの縦横比のまま縦か横がプレビューいっぱいになるまで拡大する。つまみもそこまで動き、そこから動かせる）、選択対象（プレビューでクリックして選ぶもの。「主レイヤー」はふつうのボックス。「背景」は、クリックしたボックスの背景を選ぶ（自分か外側の枠で背景を分けていれば、クリックした位置の背景の枠）。切り替える前にボックスを選んでいれば、その背景から始める。「既存レイアウト」は、「レイアウトを取り込む」で入れたボックスの組を塊ごと選び、⌘ドラッグで別の塊と入れ替える。取り込み元の印 `from_layout` が付いたものと、フォルダの中の layout.yaml と分割の形（上下・左右と子の並び）が同じものを、取り込んだ塊とみなす）
- ボックスにマウスを乗せると青く示す。クリックで選択する
- 帯の「テキストボックス」「矢印」：分割の枠とは別に、スライドの好きな位置に置く（layout.yaml ではスライドの `free:` に書く）。ボタンを押してから、プレビューでドラッグする。テキストボックスはドラッグした範囲に置き（クリックだけなら決まった大きさ）、そのまま文字を書ける。矢印は、押した点（始点）から離した点（終点）へ引く。Esc で置くのをやめる
  - 置いたものは、ドラッグで動かす（テキストボックスは、文字の外側の余白の所をドラッグする）。選んだ矢印の端をドラッグすると、その端だけを動かす
  - 左の欄で、テキストボックスは位置と大きさ、矢印は始点・終点・太さ（pt）・色・矢じり（終点・始点・両端・なし）・光彩（色・大きさ・透明度）を変える。文字の書式は、ふつうのボックスと同じくサポートパネルで変える
  - テキストボックスは、文字が入りきらなくなると高さを伸ばす。ゴミ箱か Backspace で消す。分割・統合・入れ替え・コピーはできない
- ドラッグすると、長方形になる範囲で複数のボックスを選ぶ（はみ出すボックスがあれば、そのボックスが入るまで範囲を広げる）。複数選んだときは、共通の外側の分割について、選んだ部分どうしの上下か左右の比率と、選んだ範囲全体の背景を設定する。分割の一部の部分に背景を付けると、その部分を 1 つの分割にまとめて背景を付ける。余白は、選んだボックスの 1 つずつに同じ値を設定する。選んだ範囲が外側の枠 1 つ分にちょうど重なり、その枠に余白が付いているときだけ、外側の枠の余白も出す（外側の枠はクリックでは選べないため）
- 複数選んだときは、選んだ範囲全体の幅と高さも変えられる。外側の分割の並ぶ向き（上下に並ぶなら高さ）で一部を選んだときは、選んだ部分を、合計がその長さになるように長さで固定する（中の比は保つ）。もう一方の向きと、分割の全部を選んだときは、外側の枠の大きさを変える
- 複数選んだときは、横の位置・縦の位置（テキストの揃え方、画像の位置）も、選んだボックスの 1 つずつに設定できる
- 横いっぱいの行をドラッグで選んだあと、その中から ⌘ドラッグして別の行に落とすと、行ごと入れ替える（行の高さも一緒に動く）
- ⌘C で、選んだボックス（複数でもよい）の分割と中身をコピーする。同じ大きさのボックスか範囲を選んで ⌘V を押すと、同じ分割と中身を貼り付ける（大きさが違うときは貼り付けない）
- Backspace（Delete）で、選んだボックス（複数でもよい）の中身を消して、空のテキストボックスにする。ボックスの大きさ・余白・背景・枠線・文字の設定は残す。⌘Z で戻せる
- ⌘（cmd。Windows では Ctrl）を押しながらドラッグして別のボックスの上で離すと、2 つの中身が入れ替わる（位置と大きさはそのまま）
- ボックスをクリックすると選び、そのままプレビューのボックスに文字を書ける（クリックした位置にカーソルを置く。文字の無い所なら末尾）。テキストと画像の区別は無く、どのボックスにも文字を書ける。画像は文字の裏に置く。書いている文字の中では、ドラッグで文字を選ぶ。Enter は段落の区切り、Shift+Enter は段落の中の改行。Esc で選択を外す。書いている途中はプレビューを描き直さず、選択を外したとき（別のボックスを選んだとき）に描き直して、文字の高さにボックスを合わせる
- ボックスを選んでいるあいだ、文字の書式のパネル（サポートパネル）を、まずボックスのすぐ上に出す（上に入らなければ下・右・左。ボックスが大きくてどこにも入らなければ、書いているカーソルの右に出し、カーソルが動くと追いかける）。上の「書式」のつまみを持ってドラッグすると動かせる。選択を外すと消える。書式のボタンは PowerPoint のホームに似せている
  - B・I・x²・x₂：選んだ範囲を太字・斜体・上付き・下付き（B・I は、文字を選んでいなければボックス全体）
  - U：一重線の下線（選んだ部分がすでに下線なら外す）。▾ で一重線・二重線・画像の線。画像の線は、太さ（pt）を決めて「Finder から選ぶ…」で画像を選ぶと、画像を縦横比を保たずに細長く伸ばして、文字の下に引く。一度選んだ画像（とこの文書で使っている画像の線）は、次から ▾ の候補に出る
  - A：文字の色。A の右の見本は、選んだ部分の色（選んでいなければボックス全体の文字の色）。▾ で、このスライドで使っている色・ほかの色・色を外す
  - 大きさの欄（pt）：文字を選んでいればその部分、選んでいなければボックス全体の文字の大きさ。続けて数字や ↑↓ で変えられる
  - 箇条書き：カーソルのある段落（選んだ段落）の行頭に「•」を付ける（もう一度押すと外す）。▾ で「通常」か「不可視」（「•」を描かず字下げだけ）
  - 光彩（黄色くぼかした A）：文字の光彩を付ける・外す
  - 画像（絵のアイコン）：▾ で「Finder から選ぶ…」か、フォルダの画像を選ぶ。画像は文字の裏に置く。「画像を外す」で外す
    - HEIC（iPhone の写真）も選べる（左の欄の画像・背景の画像の選択肢にも出る）。layout.yaml には HEIC のファイル名をそのまま書き、JPEG のファイルは作らない。ブラウザは HEIC を表示できないので、プレビューと PPTX・PDF の書き出しのときに、メモリの中で JPEG に変えて使う（1枚に数秒かかる。PPTX には JPEG として入る）。コマンドの `bin/slide.js` では HEIC は使えない
  - 書式のボタンのすぐ下で、選んだボックスのフォント（英語用・日本語用）を選ぶ
  - 「そのほかの文字の設定」を開くと、揃え方（横・縦）・行間・段落の間隔・下地（色と透明度）・光彩の色・見出しアイコン・「テキストの下に生じた余白を別のボックスにする」を変えられる
- 左の欄（1 つ選んだとき）は、ボックスの大きさ（幅と高さ。長さで指定か比率で指定）、「レイアウトを取り込む…」（下）、画像の収め方・位置・トリミング、余白（ふだんは上下と左右を 1 つずつの欄で同時に変える。「上・右・下・左を別々に設定する」を開くと 4 方向を別々に変えられる。「背景ごと余白を設ける」で背景と枠線も内側に縮める）、背景、枠線。変えた内容は layout.yaml に書き込まれる（コメントは残る）
- 「画像を見ながらトリミング…」か、プレビューで画像のあるボックスをダブルクリックすると、元画像の上で範囲をドラッグして決める画面が開く。この画面でも収め方（切らずに全体を収める など）を選べる。Enter で適用
- 「レイアウトを取り込む…」を押すと、フォルダの中のサブフォルダにある layout.yaml（例：`fig_intro/layout.yaml`）の 1 枚を選んで取り込める。そのレイアウトのボックスの組み合わせ（分割・比率・文字・画像・背景）を、選んだボックスの中身として layout.yaml に写す。写した後はこのスライドの普通のボックスになり、1 つずつ選んで直せる（元のファイルとはつながらない。元を直しても反映されない）。ボックスの大きさが元のスライドと違うときは、縦横比を保って収まる倍率で、長さ・文字の大きさ・光彩・枠線を縮める（元とほぼ同じ大きさなら数値はそのまま）。中の画像の場所は `fig_intro/art_bg.png` のように、このフォルダからの場所に直す。このスライドですでに使っている id は外す。⌘Z で取り込む前に戻せる
- 長さで指定するとその部分は固定されるが、同じ並びの部分がすべて固定になるときは、書き換えた部分の隣を比率に戻して残りの長さを受け取らせる（隙間が残らないように）
- 余白・背景・枠線の欄の「背景を編集」を押すと、そのボックスの背景だけを編集する状態になる。プレビューでは中身を薄く出し、背景の枠だけを選べる。上の「分割」「統合」「削除」とドラッグでの複数選択では、背景の枠を分けたり、まとめたり、消したり、選んだりする。中身のボックスの分割は変わらない。分けた枠ごとに背景（色・画像）と大きさを設定する。分けると、分けた枠のそれぞれに元の背景を写す。「背景の編集を終える」（何も選んでいないときは Esc）で戻る。分けずに終えたときは、もとの書き方に戻す。テンプレートの一部のボックスでは使えない
- 分割すると、元のボックスの余白は、分けた内側のボックスの 1 つずつに写す（外側の枠には名前・背景・枠線だけを残す）
- ゴミ箱は、ドラッグで複数選んだときも、選んだボックスをまとめて消す。消した場所は、すぐ下（左右に並ぶときは右）のボックスが伸びて埋める（組の中でいちばん下・右のボックスを消したときは、消した分だけ組を縮め、組の外側で見た目のすぐ下・右のボックスが伸びる。組に余白などが付いていてもよい。それも無ければ、すぐ上・左が伸びる）。ほかのボックスの大きさは変えない
- 左右に並ぶ組がどれも同じ位置で上下に分かれているとき（例：CA・PCA・ZPCA の列が、どれも「文字＋下の空き」に分かれている）に下の空きだけを選ぶと、並びを「上段の文字／下段の空き」に組み替えてから統合・削除する（見た目は変わらない）。上下と左右を入れ替えた場合も同じ
- 統合・削除は、選んだボックスだけを対象にする。選んだボックスが、同じ向きに分けた組の一部（例：テキストと、その下に分けた空き）のときは、その組を外側の並びに展開してから扱うので、選んでいないボックスは残る
- テキストを入れると、テキストのボックスを文字の高さに合わせ、下に余った部分を別のボックス（空き）にする。文字を打った瞬間に、高さを変える必要があるかを測り、要ればすぐ合わせる。日本語入力の変換中は、描き直すと変換中の文字が壊れるので、枠の線だけで先に分けた形を見せ、確定したときに合わせる。サポートパネルの「そのほかの文字の設定」の「テキストの下に生じた余白を別のボックスにする」で切り替える（最初は入っている。外すと 1 つのボックスに戻し、`split_below: false` と書く）。文字を足したり大きさを変えたりすると、高さを合わせ直す。テキストのボックスを複数選んだときも、この切り替えで 1 つずつに設定できる。揃え方（縦）が中央・下のとき、余りが 0.5 cm に満たないときは分けない
- 拡大は、いま見えている左上の点を動かさずに右下へ広げる（100% からなら、スライドの左上の角から広げる）。拡大したら、プレビューを上下左右にスクロールできる
- 画像のボックスで、画像の上下に隙間があるとき（「切らずに全体を収める」で横長の画像など）は「画像の上下の余白を詰める」が出る。押すと、ボックスの高さを画像の高さ（余白を含む）まで縮め、空いた分はすぐ下のボックスが上に伸びて受け取る（空きのボックスは作らない）。左右に並ぶ画像をまとめて選んだときは、段全体を、いちばん高い画像に合わせて縮める
- 「統合」は、ドラッグで選んだボックスを 1 つにまとめる。まとめたボックスの内容は、選んだ中でいちばん上か左にある、内容のあるボックスのものを使う（ほかのボックスの内容は、確かめずに消す。⌘Z で戻せる）
- ⌘Z で、あらゆる書き換えを 1 つずつ元に戻す。⌘⇧Z（または ⌘Y）でやり直す。ボックスに直接書いているときも、選択肢・チェック・色の欄を操作した直後も同じ（まだ書き込んでいない文字は、書き込んでから 1 回で戻す。文字を打つ欄で打ちかけのときだけ、その欄の中の取り消しになる）。文字に合わせて自動でボックスの高さを変えた分は、きっかけになった変更と一緒に 1 回で戻る
- 保存（⌘S）でフォルダに書き込む。「PPTX に書き出す」はフォルダの `out/` に書き出す。「PDF に書き出す」は印刷画面から「PDFに保存」を選ぶ

テンプレート（型）の中の枠を変えるときは、id があれば、そのスライドの `fill` に書き込む（そのスライドだけが変わる）。
id が無ければ型の定義を書き換える（型を使う全ての箇所が変わる）。後者のときは、設定欄に注意を出す。設定の誤り・文字のはみ出しの検査は、CLI の `slide check` で行う。

## コマンド

```bash
node bin/slide.js init my-poster                       # 雛形を作る
node bin/slide.js tree my-poster                       # 木と各枠の座標・大きさ・crop・dpi
node bin/slide.js check my-poster                      # 誤り・解像度・文字のはみ出し（error があれば終了コード1）
node bin/slide.js render my-poster --slide s1 --outline  # PNG（--outline で枠とidを重ねる）
node bin/slide.js render my-poster --node photos --width 1200   # 特定の領域だけ PNG
node bin/slide.js export my-poster                     # PPTX と PDF（--pptx / --pdf で片方）
node bin/slide.js import my-poster --node s1/fig --from fig_intro   # fig_intro/layout.yaml のボックスの木を、s1/fig の中身として写す（--page s2 で 2 枚目）
```

## layout.yaml の書き方

```yaml
canvas: {width: 32, height: 18, unit: cm}   # 1枚の大きさ。unit は cm / mm / in / pt / px
defaults:                                          # 全体の既定（下の「引き継ぐ設定」）
  font: {size: 24, family: Helvetica, family_ja: BIZ UDゴシック}
check: {min_dpi: 150}                              # これ未満の画像を警告
templates: {...}                                   # この文書の中だけで使う型（templates/ フォルダと同じ形）

slides:
  - id: s1
    background: "F4F6F8"
    root: <ノード>
```

### ノード

長さは数値ならキャンバスの単位。`"5mm"` のように単位付きでも書ける。文字の大きさだけは pt。

| 種類 | 書き方 | 意味 |
|---|---|---|
| 分割 | `split: rows` / `split: cols`、`children: [...]` | rows は上下に、cols は左右に並べる |
| | `ratio: [1, 2]` | 比率。`"3cm"` のような長さを混ぜると、その子は固定長になり、残りを比率で分ける。省略すると等分 |
| | `gap: 0.3` | 子と子の間隔 |
| 格子 | `grid: {rows: 2, cols: 3, gap: 0.2}`、`items: [...]` | 同じ大きさのセルに、行ごとに詰める（`order: col` で列ごと）。`gap: [行間, 列間]` も可 |
| 画像 | `image: a.png` | |
| | `crop: [左, 上, 右, 下]` | 元画像に対する割合（0〜1）。`[0.1, 0, 0.9, 1]` は左右10%ずつ切る |
| | `fit: contain / cover / stretch` | contain は切らずに収める、cover は枠いっぱいにしてはみ出しを切る、stretch は伸ばす |
| 文字 | `text: "1行目\n2行目"` | `font: {size, bold, italic, color, family, family_ja, glow}`（family は英語用、family_ja は日本語用のフォント。glow は文字の光彩で、`glow: true`（白・6 pt）か `glow: {color: "#ffffff", size: 6, opacity: 1}`。size は pt、opacity は 0〜1。PPTX では PowerPoint の「光彩」になる。画面・PDF は影を重ねた近似）、`line_height: 1.2`。文字の左に見出しアイコンを置くときは `icon: x.png`（高さは `icon_size` で pt。省くと文字の大きさ）。文字の一部の飾りは `<b>太字</b>` `<i>斜体</i>` `<sup>上付き</sup>` `<sub>下付き</sub>` `<color #C00000>色を付ける部分</color>` `<u>下線</u>` `<u double>二重線</u>` `<u img="line.png" w="2">画像の線</u>`（w は太さ。pt） `<size 18>大きさを変える部分</size>`（pt）（例：`mm<sup>2</sup>`）。段落の頭に `<li>` と書くと箇条書きになる（`<li hidden>` は「•」を描かない字下げだけの箇条書き）。画像の線は、PPTX では画面で測った位置に画像として置く（PPTX の行間は画面と同じポイントで書くので、PowerPoint でも同じ位置に来る。PowerPoint で文字を直しても線は動かない）。改行（`\n`）は段落の区切りで、`para_space`（pt）の間隔が足される。段落の中の改行は `<br>`（行間だけ） |
| | `text_bg: {color: "#ffff00", opacity: 0.6}` | 文字の下地の色。opacity は不透明度（0〜1。画面の「透明度」は % で、透明度 = 1 − opacity）。PPTX ではテキストボックスの塗りつぶしになる |
| 空き | 何も書かない（`{}` や `~`） | |

### 自由な位置の要素（`free:`）

スライドに `free:` を書くと、分割の木の上に重ねて、好きな位置に置ける（後に書いたものほど上）。座標はスライドの左上からの長さ（キャンバスの単位）。

```yaml
slides:
  - id: s1
    root: {...}
    free:
      - {x: 2, y: 3, w: 8, h: 2, text: "注目"}          # テキストボックス。ふつうのボックスと同じ設定（font・padding・background・border など）が書ける
      - {arrow: [20, 10, 12, 4], width: 3, color: "#C00000", head: end, glow: {color: "#ffff00", size: 6, opacity: 1}}
```

矢印の `arrow` は `[始点の x, 始点の y, 終点の x, 終点の y]`。`width` は太さ（pt。既定 3）、`head` は矢じりの位置（`end`（既定）/ `start` / `both` / `none`）、`glow` は光彩（`glow: true` は黄色・6 pt）。PPTX では PowerPoint の線（矢じりは「三角」）と「光彩」になる。

どのノードにも書けるもの：

- `id`：名前。CLI で `--node photos` や `s1/photos` と指定できる。テンプレートの差し込み口にもなる
- `padding`：余白。`background_inset: true` なら、背景と枠線も余白の分だけ内側に縮める。`1` / `[上下, 左右]` / `[上, 右, 下, 左]`。文字・画像・空のボックスでは、これは文字の余白で、、書かなければ上下左右に 0.5 cm の余白を設ける（なくすときは `padding: 0`）
- `image_padding`：画像の余白（ボックスの縁から画像まで）。`padding`（文字の余白）とは別に決まる。書き方は `padding` と同じで、書かなければ上下左右に 0.5 cm。サポートパネルの画像のボタンの横の「余白 文字」「画像」の欄で、上下左右に同じ値を入れられる
- `background`：色なら `"#RRGGBB"`。画像なら `{image: x.png, mode: stretch | cover, color: 下地の色, crop: [左, 上, 右, 下]}`（crop は画像のトリミング。元画像に対する割合で、残した範囲を mode に従って広げる）。mode は、stretch（既定。縦横比を変えてボックスいっぱいに広げる）、cover（縦横比を保って広げ、はみ出しを切る）。文書の一番上に書くと全スライドの背景になる（スライドごとの `background` が優先）
  - 背景だけを分けるときは、ボックスと同じ形の木で書く：`background: {split: rows, ratio: [1, 2], children: [{background: "#eeeeee"}, {background: {image: x.png}}]}`。中身のボックスの分割とは関係なく、そのボックスの背景の範囲を分ける（中は余白なしで敷く）。画面の「背景を編集」で作る。背景の枠に `padding` を書くと、その分だけ背景を枠の内側に縮める。画面の背景モードでは、枠の「余白」と「幅・高さ」を変えられる（分けた向きの長さは隣の枠とやり取りし、分けていない向きの長さは、左（上）はそのままに右（下）の余白で合わせる）
- `border: {width: 1 (pt), color: "#RRGGBB"}`

### 引き継ぐ設定

`align`（left / center / right）、`valign`（top / middle / bottom）、`fit`、`font`、`line_height` は、
親に書くと、その中のボックスすべてに同じ設定が入る（中のボックスに書けば、そちらを使う）。たとえば格子に `fit: cover` と書けば、全セルが cover になる。
どこにも書いていなければ、画像は中央・中段、文字は左・上に揃う。

### テンプレート（使い回し）

```yaml
templates:
  photos_and_note:          # 中身を空けた型
    split: rows
    ratio: ["2.4cm", 1]
    children:
      - {id: title, text: ""}
      - id: photos
        grid: {rows: 2, cols: 3}
        items: []

slides:
  - id: s1
    use: photos_and_note    # 型を使う
    fill:                   # id ごとに中身を入れる（その id のノードの設定を上書き）
      title: {text: "結果"}
      photos: {items: [{image: a1.png}, {image: a2.png}]}
```

`use` はノードの途中にも書ける（型の中に型を入れてもよい）。`use` と `fill` 以外のキー（`padding` など）は型の根を上書きする。

## AI が使うとき

1. `layout.yaml` を直接編集する（専用の編集コマンドは無い。テキストなので差分も読める）
2. `slide tree` で数値を、`slide render --outline` で見た目を確かめる。PNG は画像として読む
3. `slide check` で error が無いことを確かめてから `slide export`

`tree --json` は全要素の絶対座標を JSON で出す（整列の検査ツールなどに渡せる）。

## 既知の制約

- PPTX を PowerPoint で手直ししても、`layout.yaml` には戻らない。正本は常に設定ファイル
- 文字の折り返しとはみ出しの判定は Chrome で測る。PowerPoint とはフォントの寸法が少し違うため、ぎりぎりの枠では PPTX 側だけはみ出すことがある
- フォントは英語用（`font.family`）と日本語用（`font.family_ja`）を別々に選ぶ。日本語の字（かな・漢字・全角の記号）は日本語用、それ以外（英数字など）は英語用のフォントで書く。PPTX でも同じに分けて書く（英語用は latin、日本語用は ea）
  - 英語用：BIZ UDゴシック・ヒラギノ角ゴシック・Noto Sans JP・メイリオ・Helvetica・Arial・Times New Roman（既定は Helvetica）
  - 日本語用：BIZ UDゴシック・ヒラギノ角ゴシック・Noto Sans JP・メイリオ（既定は BIZ UDゴシック）
  - PPTX にはフォントそのものは入らない。開く PC にそのフォントが無いと、別のフォントに置き換わる（BIZ UDゴシック・メイリオは Windows に標準で入っている。ヒラギノ角ゴシックは Mac だけ。Helvetica は Windows では Arial などに置き換わることがある）
- EXIF の回転情報付きの写真は、縦横を入れ替えて計算するが、PPTX での表示は未確認
- 図形（矢印以外）・表・箇条書きの書式（字下げ）は未対応
- BIZ UDゴシックと Noto Sans JP は、プレビューと PDF では Google Fonts から読み込む（PDF は読み込み終えてから書き出すので、フォントごと入る）。PPTX には英語の名前（BIZ UDGothic）で書く。PowerPoint では、その PC に入っているときだけ同じ字形になる
- ブラウザ版で設定欄から書き換えると、YAML の `{a: 1}` が `{ a: 1 }` のように書き直される（意味は同じ）
