slide-creator

操作

  • クリック：枠を選ぶ（いちばん内側の枠）
  • ダブルクリック / Enter：選んだ枠を拡大して表示
  • Esc：親の枠を選ぶ
  • ⌘S / Ctrl+S：保存

考え方

正本はプロジェクトフォルダの layout.yaml。左の「設定」で変えた内容は、その YAML に書き込まれる（「YAML」タブで直接書き換えてもよい）。保存するまでファイルは変わらない。

テンプレート（型）の中のノードは、id があればそのスライドの fill に書き込み、id が無ければ型の定義そのものを書き換える（型を使う全ての箇所に効く）。

書き方の詳細はリポジトリの README を参照。

「フォルダを開く」で、layout.yaml のあるプロジェクトフォルダを選んでください。

「見本」で、見本のプロジェクトを開けます（読むだけ）。
